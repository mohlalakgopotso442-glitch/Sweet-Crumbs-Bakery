Sweet Crumbs Bakery Website

1. Project Overview

Sweet Crumbs Bakery is a bakery website developed as part of a web design project. The website provides information about the bakery, its products and services, and allows customers to view products and make an order or enquiry.

The website was designed to have a simple, attractive and user-friendly appearance, using the cream, brown and light pink colour scheme selected in Part 1.

2. Website Pages

The website consists of six main pages:

* Home: Introduces Sweet Crumbs Bakery.
* About Us: Provides information about the bakery and its values.
* Products: Displays product categories and prices.
* Gallery: Displays bakery product images.
* Order: Allows customers to make an order or enquiry.
* Contact Us: Provides contact information and a contact form.

3. Main Features

The website includes:

* Navigation links connecting all six pages.
* A home page introducing the bakery.
* Product categories with images and descriptions.
* Product search functionality.
* Product View buttons that open the relevant Gallery category.
* Gallery search and image filtering.
* An accessible image lightbox.
* Order and contact forms with validation.
* Responsive layouts for different screen sizes.
* Hover, focus and animation effects.
* A location section with a link to Google Maps.

4. Design and Colour Scheme

The website follows the colour palette selected in Part 1:

* Cream: #f8f1e7
* Brown: #6b3e26
* Light Pink: #e8b7c8
* Soft Pink: #f8e1e8

The design is consistent across all pages.

Poppins is used for headings where available, while Arial is used for the main body text.

7. Responsive Design

The website was designed to work on desktop computers, tablets and mobile phones.

CSS media queries were used to adjust the navigation, images, product layouts and spacing for different screen sizes.

8. Part 3: JavaScript Enhancements

JavaScript was added to improve the functionality and interaction of the website.

The following features were implemented:

* Connected the external js/script.js file to the website pages.
* Added product category search functionality.
* Added gallery search functionality.
* Added dynamic loading of product categories.
* Added an accessible gallery lightbox.
* Added keyboard controls for opening and closing gallery images.
* Added form validation for the Order and Contact pages.
* Added feedback messages for user interactions.
* Added URL hash support to display selected Gallery categories.

9. Search Engine Optimisation (SEO)

SEO improvements were made to help search engines understand the website content.

The improvements include:

* Added unique page titles.
* Added meta descriptions and keywords.
* Used descriptive headings.
* Added alternative text to images.
* Used descriptive internal links.
* Added lazy loading to suitable images.
* Created a robots.txt file to provide crawling instructions.
* Created a sitemap.xml file listing the six website pages.

The website also uses descriptive page names to make navigation easier.

10. Animations and User Experience

CSS animations and transitions were used to improve the appearance of the website.

These include:

* Hover effects on navigation links and buttons.
* Image hover effects.
* Subtle entrance animations.
* Visible keyboard focus styles.
* Reduced-motion support for users who prefer fewer animations.

11. Forms and Validation

The website contains an Order form and a Contact form.

JavaScript validation checks the information entered by visitors before preparing an email.

The forms prepare an email using the visitor’s email application. Visitors must send the email themselves. The static website does not store form submissions on a server.

12. Testing

The website was tested to check that its pages and interactive features work correctly.

Testing screenshots were captured as evidence of the website’s functionality and appearance.

13. Running the Website

To view the website:

1. Open the Sweet Crumbs Bakery project folder in Visual Studio Code.
2. Open index.html.
3. Run the page using a browser or the Live Server extension.
4. Use the navigation menu to explore the different pages.

An internet connection is required for external services and online resources.

14. Conclusion

The Sweet Crumbs Bakery website provides a simple and user-friendly way for customers to learn about the bakery, view its products and make an enquiry.

The project developed from the initial HTML structure into a styled, responsive and interactive website using HTML, CSS and JavaScript.

SEO improvements, search functionality, interactive gallery features and form validation were added to improve the overall website experience.
