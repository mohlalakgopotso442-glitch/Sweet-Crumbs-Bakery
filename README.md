# Sweet Crumbs Bakery Website

## Project Overview

Sweet Crumbs Bakery is a small bakery website created as part of a web design project. The website provides information about the bakery, its products and services, and allows customers to view products and make an order or enquiry.

The website was designed to have a simple, attractive and user-friendly appearance.

## Website Pages

The website consists of the following pages:

- Home
- About Us
- Products
- Gallery
- Order
- Contact Us

## Main Features

The website includes:

- A navigation menu linking all the main pages.
- A home page with an introduction to the bakery.
- An About Us page with information about the bakery and its values.
- A Products page showing different product categories and prices.
- A Gallery page displaying bakery products.
- Product View buttons that take users to the relevant Gallery category.
- An Order page with an order/enquiry form.
- A Contact Us page with contact details and a contact form.
- Images of the bakery products.
- Hover and focus effects for links and buttons.
- Responsive design for different screen sizes.

## Design

The website uses the colour palette chosen during Part 1:

- Cream: #f8f1e7
- Brown: #6b3e26
- Light Pink: #e8b7c8
- Soft Pink: #f8e1e8

The design was kept simple and consistent across all pages.

Poppins was used for headings where available, while Arial was used for the main body text.

## Technologies Used

The following technologies were used to create the website:

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive media queries
- Visual Studio Code
- GitHub

## File Structure

The project contains the following main files and folders:

- index.html
- about.html
- products.html
- gallery.html
- order.html
- contact.html
- style.css
- images/

The images folder contains the images used throughout the website.

## Responsive Design

The website was designed to work on different screen sizes, including computers, tablets and mobile phones.

CSS media queries were used to adjust the layout, navigation, images and product grids for smaller screens.

## Testing

The website was tested after development to make sure that the pages, links, buttons, images and forms were working correctly.

The following were tested:

- Navigation links
- Product View buttons
- Order Now button
- Order form
- Contact form
- Images
- Responsive layout
- Hover and focus effects

The tests were successful and screenshots were taken as evidence of the testing.

## Conclusion

The Sweet Crumbs Bakery website provides a simple and user-friendly way for customers to learn about the bakery, view its products and make an enquiry or order.

The website was developed using HTML and CSS while following the design ideas and colour palette established in Part 1.
